# 비밀 우체통 Google Sheets 연결 설정

현재 사이트는 GitHub Pages에서 정적 호스팅되므로, Google Apps Script를 서버(백엔드)로 배포해야 합니다. 저장할 스프레드시트와 Apps Script 프로젝트를 직접 소유·관리하세요.

## 1. 스프레드시트와 Apps Script 만들기

1. 새 Google 스프레드시트를 만들고 URL의 `/d/`와 `/edit` 사이에 있는 스프레드시트 ID를 복사합니다.
2. 스프레드시트에서 **확장 프로그램 → Apps Script**를 열거나 [script.google.com](https://script.google.com/)에서 새 프로젝트를 만듭니다.
3. 편집기의 기본 코드 전체를 지우고 이 저장소의 `secret-gas/Code.gs` 내용을 붙여 넣은 뒤 저장합니다.
4. Apps Script의 **프로젝트 설정 → 스크립트 속성**에 다음 속성을 추가합니다.
   - `SHEET_ID`: 1단계에서 복사한 스프레드시트 ID
   - `NOTIFY_EMAIL`: 선택 사항. 새 메시지 알림을 받을 이메일 주소. 빈 값이면 이메일을 보내지 않습니다.
5. Apps Script 편집기에서 `doPost`를 직접 실행하지 마세요. 웹 앱으로 배포해야 합니다.

## 2. 웹 앱으로 배포하기

1. **배포 → 새 배포 → 유형 선택 → 웹 앱**을 선택합니다.
2. 실행 사용자: **나**. 액세스 권한: **모든 사용자**로 설정한 뒤 배포합니다. 이 설정은 Google 계정 로그인 없이 제출을 받기 위한 것입니다.
3. 권한 요청을 검토하고 허용한 다음, 끝에 `/exec`가 붙은 웹 앱 URL을 복사합니다.
4. `secret.html`에서 아래 설정 줄의 빈 따옴표 안에 URL을 붙여 넣고 저장/배포합니다.

```js
var SHEETS_WEB_APP_URL = "https://script.google.com/macros/s/배포ID/exec";
```

5. Apps Script를 수정할 때는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 합니다.

## 3. 동작 확인 및 개인정보 안내

- GitHub Pages의 비밀 우체통 페이지를 열고 테스트 메시지를 보내세요. 스프레드시트에 `고민함` 탭이 만들어지고 접수 시각, 이름, 내용이 추가됩니다.
- 브라우저의 CORS 제한 때문에 화면은 Apps Script의 저장 성공 응답을 읽을 수 없습니다. 화면은 전송 요청을 보냈음을 알리며, 실제 저장 여부는 시트에서 확인해야 합니다.
- 익명 접근을 위해 웹 앱 URL은 페이지 소스에 공개됩니다. URL을 비밀키처럼 취급하지 마세요. 누구나 요청을 보낼 수 있으므로 스프레드시트 접근 권한은 신뢰하는 담당자에게만 공유하고, 시트를 공개 게시하지 마세요.
- 고민 내용은 민감한 개인정보일 수 있습니다. 학생에게 수집 목적과 확인 담당자를 알리고, 불필요한 개인정보를 적지 않도록 안내하세요. 보관 기간을 정하고 필요할 때 삭제하세요.
- `NOTIFY_EMAIL`은 선택 사항이며, Apps Script 소유자 계정의 메일 발송 할당량과 권한을 사용합니다.
