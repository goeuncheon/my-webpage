# 우리 반 생일 달력 Google Sheets 연동

GitHub Pages는 정적 호스팅이므로 Google Apps Script를 백엔드로 배포해야 합니다. 이 파일의 웹 앱 URL은 페이지 소스에 공개됩니다. 따라서 생일 목록에는 공개되어도 괜찮은 정보만 넣고, 스프레드시트를 공개 공유하지 마세요.

## 설정

1. Google 스프레드시트를 만들고 URL의 `/d/`와 `/edit` 사이에 있는 ID를 복사합니다.
2. 스프레드시트에서 **확장 프로그램 → Apps Script**를 열거나 [script.google.com](https://script.google.com/)에서 새 프로젝트를 만듭니다.
3. 편집기의 코드를 지우고 이 저장소의 `birthday-gas/Code.gs`를 붙여넣어 저장합니다.
4. Apps Script **프로젝트 설정 → 스크립트 속성**에 다음을 추가합니다.
   - 속성 이름: `BIRTHDAY_SHEET_ID`
   - 값: 스프레드시트 URL의 `/d/`와 `/edit` 사이에서 복사한 ID
   - 이미 `SHEET_ID` 속성을 설정했다면 재사용할 수 있습니다.
5. **배포 → 새 배포 → 유형 선택 → 웹 앱**에서 실행 사용자는 **나**, 액세스 권한은 **모든 사용자**로 설정해 배포하고 권한을 승인합니다. 웹 앱 URL 끝은 `/exec`여야 합니다.
6. `birthday.html`의 설정 줄에 URL을 입력합니다.

```js
var BIRTHDAY_WEB_APP_URL = "https://script.google.com/macros/s/배포ID/exec";
```

7. `birthday.html`을 저장하고 GitHub Pages에 반영되면 페이지에서 목록을 확인하고 테스트 등록을 해 보세요. Apps Script가 `생일` 탭과 첫 행 제목을 자동으로 만듭니다.

## 주의

- 페이지는 JSONP로 목록을 읽고 폼 POST로 새 생일을 보냅니다. 브라우저의 CORS 제한 때문에 등록 화면은 실제 저장 성공 응답을 확인하지 못하므로, 테스트 후 스프레드시트에서 행이 추가됐는지 확인하세요.
- Apps Script 코드를 수정했다면 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포하세요.
- 웹 앱은 익명 접근을 위해 공개되어야 하며 URL도 공개됩니다. 이 설정은 접근 제어가 아니므로 URL을 비밀키로 취급하지 마세요. 필요하면 등록 기능을 제한하거나 별도 인증이 있는 백엔드를 사용하세요.
- 생일은 개인정보입니다. 학생과 보호자에게 수집 목적과 열람자를 알리고, 필요한 최소한의 정보만 저장하며, 보관 기간 이후 삭제하세요.
